# pacs008-loader-mt103 v0.0.16

Released in lockstep with `pacs008` 0.0.16. The parser is unchanged:
`parse_mt103` returns the same records for the same input as 0.0.15.

## Python 3.11 or newer

Python 3.10 is no longer supported. `requires-python` is `>=3.11`, as
in the `pacs008` core, and CI tests 3.11 to 3.14. On 3.10, pip keeps
resolving 0.0.15.

## Supply chain and CI

- `pacs008 >= 0.0.16, < 1`.
- The CI audit environment (`requirements/audit.txt`) is compiled for
  Python 3.12 and floors `filelock >= 4.2.1` (GHSA-9vhv-jxww-xfm5,
  GHSA-567q-5qvw-pf92, GHSA-v4x8-3wr5-3wq8).
- The hash-pinned requirement trees are compiled for 3.11 and lose
  their 3.10-only pins.
- The GitHub release is titled `pacs008-loader-mt103 0.0.16`.

## Upgrading

`pip install --upgrade pacs008-loader-mt103` on Python 3.11 or newer.
